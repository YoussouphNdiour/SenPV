# Prompt 03 — Internationalisation (FR/EN)

## Contexte

Configurer next-intl pour le support bilingue français/anglais dans SenPV.
Le français est la langue par défaut. Toute chaîne affichée à l'utilisateur doit passer par le système i18n.

## Dépendances

- Prompt 00 (project setup)

## Tâches

### 1. Configuration next-intl

**`frontend/src/i18n/config.ts`** :
```typescript
export const locales = ['fr', 'en'] as const;
export type Locale = (typeof locales)[number];
export const defaultLocale: Locale = 'fr';
```

**`frontend/src/i18n/request.ts`** — getRequestConfig pour next-intl

**`frontend/next.config.ts`** — ajouter le plugin next-intl

**`frontend/src/middleware.ts`** — intégrer le middleware next-intl avec la détection de locale (cookie, header Accept-Language, défaut FR)

### 3. Messages EN

**`frontend/messages/en.json`** — traduction anglaise complète de toutes les clés ci-dessus.

### 4. Intégration dans les composants

- Chaque page/composant utilise `useTranslations('namespace')` pour accéder aux traductions
- Le layout principal inclut un sélecteur de langue (FR/EN) dans le header
- La langue est persistée dans le cookie `NEXT_LOCALE` et dans `users.locale` en BDD
- Changer la langue met à jour l'URL (`/fr/dashboard` ↔ `/en/dashboard`)

### 5. Sélecteur de langue

**`frontend/src/components/layout/LocaleSwitcher.tsx`** :
- Dropdown avec drapeaux 🇫🇷 / 🇬🇧 (ou texte FR/EN)
- Change la locale et redirige vers la même page dans la nouvelle langue
- Met à jour le cookie `NEXT_LOCALE`
- Si l'utilisateur est connecté, met à jour `users.locale` en BDD

## Critères d'acceptance

- [ ] `fr.json` et `en.json` contiennent les mêmes clés
- [ ] `/fr/dashboard` affiche en français, `/en/dashboard` en anglais
- [ ] Le sélecteur de langue change la langue et redirige
- [ ] La langue est persistée (rechargement conserve la langue)
- [ ] Aucune chaîne en dur dans les composants — tout passe par `useTranslations`
- [ ] Les messages d'erreur auth sont traduits
- [ ] Le format des nombres suit la locale (1 234,56 en FR, 1,234.56 en EN)
